# Meta Ad Performance Dashboard

## 🎯 Objective

To analyze advertising performance and identify trends in impressions,
clicks, engagement and conversions across different campaigns,
demographics and advertising platforms.

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze Meta advertising
performance across Facebook and Instagram.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization

## 📈 Key KPIs

- Impressions: 112.4K
- Clicks: 12.9K
- Shares: 685
- Comments: 1.3K
- Purchases: 678
- Engagement: 14.9K
- CTR: 11.48%
- Engagement Rate: 13.27%
- Conversion Rate: 5.25%
- Purchase Rate: 0.60%
- Total Budget: $2.5M
- Average Budget: $50.7K

## 📊 Dashboard Features

- Dynamic measures
- Gender-wise analysis
- Age-wise analysis
- Country-wise analysis
- Monthly trends
- Weekly trends
- Hourly trends
- Ad-type performance
- Campaign filtering
- Target-interest filtering
- Facebook vs Instagram analysis
